# Case study: the four-fault drill

Four things on one planet are wrong, and each shows its fault in a different place. This drill tests whether you pick the right place without being told.

## Things worth knowing before you start

- Start with one roll call of the whole planet and sort the problems by status.
- Image problems and `Pending` are read in Events. Crashes are read in logs. A silent Service is read by comparing labels.
- Change one thing, then check that it worked, before the next fault.
- Write down what you saw and what you changed. It makes the last fault easier.

## What to do

Use the method: observe, narrow, guess, change one thing, verify. Repeat four times and submit.
