# Section 030: Read The Terminal And YAML

Astronaut, every mission is typed into a terminal and flown from a file. This section makes both calm. You learn to move around the file system, chain commands with pipes, and read and write the YAML that Kubernetes uses.

## Modules

This section has two modules and a capstone. Each module has its own playground and one graded mission.

| Module | What you learn | Playground | Graded mission |
| --- | --- | --- | --- |
| [Find Your Way Around The Terminal](./module-01/course.md) | `pwd`, `ls`, `cd`, files, pipes, `grep`, variables, `nano` | `ats-000-playground-030-01`: the planet `terminal-lab` with `alpha`, `beta` and `gamma` | [Find The Silent Ships](./module-01/labs/lab-01/README.md) |
| [Read And Write YAML](./module-02/course.md) | Maps, lists, indentation, quotes, the four top-level keys, dry run, `kubectl explain` | `ats-000-playground-030-02`: the planet `draft-lab` with the healthy `sample` | [Write The Radar Fleet Order](./module-02/labs/lab-01/README.md) |
| Capstone | Pipes, a file and a Deployment in one mission | none | [Capstone: The Deck Check](./capstone/labs/lab-01/README.md) |

The section ends with a [knowledge check](./quiz.yaml). The [final quiz](../final-domain-quiz.yaml) covers all sections.

## What you need

A terminal and the setup from the first section. Each lab needs about 1.2 GB of memory for the container engine, and the playground should be stopped while a lab runs.
